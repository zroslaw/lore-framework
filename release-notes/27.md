# Release Notes -- Version 27

## Summary

Version 27 completes the public-facing **Lore Agents** onboarding pass: the plugin identity, README,
quickstart, install guides, marketplace copy, and first-steps guide now present the framework as
Lore Agents consistently. It also fixes Codex invocation guidance so the Codex engine profile points
users at Codex skills instead of Claude-style slash commands.

## Clear Plugin Cache

This release **modifies** plugin manifests, engine install guides, marketplace metadata, and the
SKILL-referenced Codex engine profile `docs/engines/codex.md`. **Refresh before expecting the new
Lore Agents identity and Codex invocation guidance to appear reliably.**

Repo migration required: **no** -- existing agent repos auto-stamp on next boot. Cache-clear
**is** required.

After upgrading:

1. **Claude Code:** `rm -rf ~/.claude/plugins/cache/lore-framework/` (targeted), or
   `rm -rf ~/.claude/plugins/cache/` (broader fallback). Exit the current session and start a new one.
2. **Cursor:** run `bash /path/to/lore-framework/scripts/cursor-refresh-plugin`, then start a fresh
   `cursor-agent --plugin-dir /path/to/lore-framework` session.
3. **Codex:** `codex plugin marketplace upgrade lore-framework` (or `codex plugin add lr@lore-framework`),
   then start a fresh Codex session.

If you skip the refresh, prior manifest metadata and cached engine guidance can remain loaded. See
`docs/doctor-stale-plugin-cache.md` (Claude) or `docs/doctor-cursor-session-without-plugin.md`
(Cursor missing skills).

## Status

Stable on Claude Code. **BETA on Codex** and **BETA on Cursor** for the core lifecycle surface.
`/lr:takeover` remains **BETA** on all engines.

## What's New

### Lore Agents identity and onboarding

- Plugin display names now use **Lore Agents** across Claude Code, Cursor, Codex, and native Codex
  marketplace metadata.
- `README.md` now routes newcomers through three concrete paths: create a first agent, join a team
  with an existing lore repo, or install for a specific engine.
- New top-level onboarding docs:
  - `QUICKSTART.md`
  - `FIRST-STEPS.md`
  - `INSTALL-CLAUDE.md`
- Existing engine guides (`INSTALL-CODEX.md`, `INSTALL-CURSOR.md`) were refreshed for the new
  product framing and clearer installer-agent flow.
- `MARKETPLACE.md` and `PRIVACY.md` were aligned with the public submission surface.

### Codex invocation guidance

- `docs/engines/codex.md` now describes Codex skill invocation directly instead of implying that
  the agent should type Claude-style `/lr:<skill>` commands.
