# Release Notes — Version 22

## Summary

Version 22 adds **top-level engine install guides** for Codex and Cursor, plus explicit
**Codex plugin refresh guidance** in the runtime docs so version mismatches point users at the
right remedy instead of a Claude-specific update command.

## Clear Plugin Cache

This release adds and updates plugin-shipped runtime docs (`docs/version-check.md`,
`docs/engines/codex.md`, `docs/engines/cursor.md`), adds a bundled helper script
(`scripts/codex-refresh-plugin`), and adds top-level install guides. The existing plugin cache must
be refreshed before Claude Code will load the new guidance.

After upgrading:

1. `rm -rf ~/.claude/plugins/cache/lore-framework/` (targeted; preserves other plugins' caches), or
   `rm -rf ~/.claude/plugins/cache/` (broader fallback), or run the workspace's
   `./clear_plugin_cache.sh` if present.
2. Exit your current Claude Code session and start a new one.

If you skip this step, the prior version's guidance remains loaded until the cache refreshes. See
`docs/doctor-stale-plugin-cache.md` for diagnosis, or run `/lr:doctor`.

## Status

Stable on Claude Code. **BETA on Codex** and **BETA on Cursor** for the core lifecycle surface.
Release-notes-only — **no migration required**: all changes are inside the plugin; existing agent
repos upgrade on next boot.

## What's New

### Dedicated install guides at the repo root

Two user-facing, top-level guides now sit next to `README.md`:

- `INSTALL-CODEX.md` — canonical Codex install, refresh, and team-automation instructions
- `INSTALL-CURSOR.md` — canonical Cursor install and refresh instructions

The intent is operational: an engine or human can be pointed at one file directly, including from a
fresh install or a GitHub view, without first navigating the internal procedure docs.

### Codex version-mismatch remedy is now engine-specific

`docs/version-check.md` no longer tells every engine to run a generic `/plugin update lr` style
command. On Codex, the mismatch warning now points at the real refresh path:

- `codex plugin add lr@lore-framework`
- and, for Git-backed marketplaces first, `codex plugin marketplace upgrade lore-framework`

The warning also tells the user to restart Codex and points at `INSTALL-CODEX.md`.

### Codex refresh helper script

The bundled helper `scripts/codex-refresh-plugin` wraps the practical refresh flow:

```bash
scripts/codex-refresh-plugin
```

It attempts a marketplace upgrade first, tolerates the local-source case where that step is
unsupported, then reinstalls `lr@lore-framework`.

### Cursor install guidance is now explicit

`docs/engines/cursor.md` now states the currently verified operational path plainly:
`cursor-agent --plugin-dir /absolute/path/to/lore-framework`, with restart-after-refresh guidance
and a pointer to `INSTALL-CURSOR.md`.
