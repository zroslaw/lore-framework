# Release Notes — Version 25

## Summary

Version 25 ships **Cursor ops parity** with Codex: install and refresh helper scripts, a full
`INSTALL-CURSOR.md` guide, README engine-neutral sweep, canonical mid-session fallback in
`docs/engines/cursor.md`, doctor coverage for sessions without the plugin loaded, and
**three-manifest** version discipline (`.cursor-plugin/plugin.json` now enforced by `/lr:check` #19).

Tier-1 lifecycle semantics are unchanged. No new `/lr:*` skills.

## Clear Plugin Cache

This release adds operator scripts, expands Cursor install/refresh documentation, registers a new
doctor ailment, and updates SKILL-referenced procedure docs (`docs/engines/cursor.md`,
`docs/doctor.md`, `docs/check.md`, `docs/conventions.md`). Refresh before expecting the new
behavior to appear reliably.

After upgrading:

1. **Claude Code:** `rm -rf ~/.claude/plugins/cache/lore-framework/` (targeted), or
   `rm -rf ~/.claude/plugins/cache/` (broader fallback). Exit the current session and start a new one.
2. **Cursor:** run `bash /path/to/lore-framework/scripts/cursor-refresh-plugin`, then start a fresh
   `cursor-agent --plugin-dir /path/to/lore-framework` session.
3. **Codex:** `codex plugin add lr@lore-framework`, then start a fresh Codex session.

If you skip the refresh, the prior version's skill catalog and procedure docs can remain loaded.
See `docs/doctor-stale-plugin-cache.md` (Claude) or `docs/doctor-cursor-session-without-plugin.md`
(Cursor missing skills).

## Status

Release-notes-only — **no migration required**: existing agent repos upgrade on next boot.

## What's New

### Cursor install and refresh scripts

- `scripts/install-cursor-plugin` — post-clone helper (validates checkout, optional pull, optional
  `--symlink` for local plugins dir)
- `scripts/cursor-refresh-plugin` — `git pull --ff-only` + VERSION diff + fresh-session reminder

Two-step install: `git clone` → `install-cursor-plugin` → `cursor-agent --plugin-dir`.

### INSTALL-CURSOR.md depth parity

Restructured to match `INSTALL-CODEX.md`: install sequence, team automation, refresh contract,
mid-session fallback pointer, troubleshooting table.

### README engine-neutral sweep

Engine syntax legend, multi-engine Quick Start, skills table with Cursor column, `AGENTS.md` /
`.cursor/skills/` in directory layout, Cursor self-install block.

### Mid-session fallback (canonical)

`docs/engines/cursor.md` now documents file-driven execution via `.cursor-skills/lr-<skill>/SKILL.md`
when plugin skills are unavailable — including non-mechanical name mapping (`lr-merge` →
`process-merge.md`).

### Doctor: cursor session without plugin

New ailment `docs/doctor-cursor-session-without-plugin.md`, catalog-registered under Plugin &
runtime. Differential routing to stale-cache vs version mismatch vs fallback.

### Three-manifest check #19

`/lr:check` #19 and `conventions.md` § Plugin Manifest Versioning now cover
`.cursor-plugin/plugin.json` alongside the Claude manifests. Cursor manifest bump is consistency
hygiene — not claimed as a Cursor cache-detection lever.

manifests). Cursor fallback smoke validated file-driven boot without loaded plugin.
