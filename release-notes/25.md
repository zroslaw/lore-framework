# Release Notes — Version 25

## Summary

Version 25 has three strands. **(1) The workspace slice** reworks how a workspace is bootstrapped and
refreshed: `/lr:workspace-sync` → **`/lr:workspace-pull`** (now a two-level pull — the workspace repo,
then `lore-workspace.md` workspace-level repos, then `lore-repo.md` domain-level repos, plus
`.gitignore` plumbing for a git-tracked workspace), and `/lr:init` → **`/lr:workspace-init`** (a full
setup wizard that scaffolds `lore-workspace.md`, an optional workspace git root, `README.md`, and the
memory-file conventions block). Both are **hard renames** (no alias). **(2) Cursor ops parity** with
Codex: install/refresh helper scripts, a full `INSTALL-CURSOR.md`, README engine-neutral sweep,
canonical mid-session fallback in `docs/engines/cursor.md`, and doctor coverage for sessions without
the plugin loaded. **(3) Native Codex plugin packaging** (`.codex-plugin/plugin.json` +
`.agents/plugins/marketplace.json`) so Codex loads Lore through its own supported manifest path with a
display name, logo, and category in the `/plugins` browser.

Version discipline is now **four-manifest** (`.cursor-plugin/plugin.json` and `.codex-plugin/plugin.json`
both enforced by `/lr:check` #19), and `/lr:check` gains **#22** (workspace child repos gitignored) and
**#23** (legacy `lr:init` markers). Tier-1 lifecycle semantics are unchanged.

## Clear Plugin Cache

This release **renames two skills** (`workspace-sync` → `workspace-pull`, `init` → `workspace-init`,
with their scripts, docs, and Cursor wrappers), adds operator scripts, expands Cursor install/refresh
documentation, registers a new doctor ailment, and updates SKILL-referenced procedure docs
(`docs/workspace-pull.md`, `docs/workspace-init.md`, `docs/engines/cursor.md`, `docs/doctor.md`,
`docs/check.md`, `docs/conventions.md`). **The renamed skills will not resolve under their old names
until you refresh** — refresh before expecting the new behavior to appear reliably.

After upgrading:

1. **Claude Code:** `rm -rf ~/.claude/plugins/cache/lore-framework/` (targeted), or
   `rm -rf ~/.claude/plugins/cache/` (broader fallback). Exit the current session and start a new one.
2. **Cursor:** run `bash /path/to/lore-framework/scripts/cursor-refresh-plugin`, then start a fresh
   `cursor-agent --plugin-dir /path/to/lore-framework` session.
3. **Codex:** `codex plugin add lr@lore-framework`, then start a fresh Codex session.

If you skip the refresh, the prior version's skill catalog and procedure docs can remain loaded.
See `docs/doctor-stale-plugin-cache.md` (Claude) or `docs/doctor-cursor-session-without-plugin.md`
(Cursor missing skills).

## Status

Stable on Claude Code. **BETA on Codex** and **BETA on Cursor** for the core lifecycle surface.

**Migration:** `migrations/25.md` ships with the release. It writes nothing to a lore agent repo
(version stamp only — Write Paths `(none)`); its one real effect is nudging you to run
`/lr:workspace-init` once to migrate a workspace still on the legacy `<!-- lr:init -->` markers and
old payload. `/lr:check` #23 flags the same condition. Agent repos otherwise upgrade on next boot.

## What's New

### Workspace slice: `workspace-pull` + `workspace-init`

- **`/lr:workspace-pull`** (renamed from `workspace-sync`) — pulls fresh workspace state in phases:
  (0) pull the workspace repo itself if it is git-tracked, dirty-guarded and never fatal; (1) clone
  workspace-level repos declared in `lore-workspace.md`; (2) discover each `lore-repo.md` and clone
  domain-level repos; (3) append `.gitignore` entries for declared child repos in a git workspace,
  idempotently; (4) pull every top-level git repo. Backward compatible: no `lore-workspace.md` → phase
  1 is a no-op and domain discovery runs exactly as before (v11 parity).
- **`/lr:workspace-init`** (renamed from `init`) — a setup wizard for a fresh workspace: interview →
  confirmation gate → write `lore-workspace.md`, optional workspace git root + `.gitignore` +
  `README.md`, run `workspace-pull`, then write the memory-file conventions block. On an already-set-up
  workspace it refreshes the memory-file section only; `--reconfigure` re-runs the interview. Migrates
  legacy `<!-- lr:init -->` markers to `<!-- lr:workspace-init -->` on first run.
- **`lore-workspace.md`** — a new optional workspace-root descriptor (`description` + block-form
  `repos:`) versioning the workspace layout. Its `repos:` is the *workspace-level* list (the top-level
  repos, including the agent repos themselves); a `lore-repo.md` `repos:` remains the *domain-level*
  list. Documented in `docs/conventions.md`.
- **Checks #22 and #23** — #22 warns when a declared child repo on disk isn't gitignored in a git
  workspace; #23 warns when a workspace still uses legacy `lr:init` markers.

### Cursor install and refresh scripts

- `scripts/install-cursor-plugin` — post-clone helper (validates checkout, optional pull, optional
  `--symlink` for local plugins dir)
- `scripts/cursor-refresh-plugin` — `git pull --ff-only` + VERSION diff + fresh-session reminder

Two-step install: `git clone` → `install-cursor-plugin` → `cursor-agent --plugin-dir`.

### INSTALL-CURSOR.md depth parity

Restructured to match `INSTALL-CODEX.md`: install sequence, team automation, refresh contract,
mid-session fallback pointer, troubleshooting table.

### README engine-neutral sweep

Engine syntax legend, multi-engine Quick Start, skills table with Cursor column, `AGENTS.md` /
`.cursor/skills/` in directory layout, Cursor self-install block.

### Mid-session fallback (canonical)

`docs/engines/cursor.md` now documents file-driven execution via `.cursor-skills/lr-<skill>/SKILL.md`
when plugin skills are unavailable — including non-mechanical name mapping (`lr-merge` →
`process-merge.md`).

### Doctor: cursor session without plugin

New ailment `docs/doctor-cursor-session-without-plugin.md`, catalog-registered under Plugin &
runtime. Differential routing to stale-cache vs version mismatch vs fallback.

### Codex native packaging

- `.codex-plugin/plugin.json` — Codex's own supported manifest (`name`/`version`/`description` +
  `skills: "./skills/"` + an `interface` block carrying `displayName`, `category`, `logo`, and
  descriptions for the install surface).
- `.agents/plugins/marketplace.json` — the native Codex marketplace file (root-source `path: "./"`,
  `policy.authentication: ON_USE`). Codex prefers it over the legacy `.claude-plugin/marketplace.json`
  fallback when present.
- Install commands are unchanged; a checkout without these files still installs via the legacy
  fallback. Validated end-to-end against `codex-cli` 0.142.5: native marketplace resolves, plugin
  version resolves from `.codex-plugin/plugin.json`, skills load from `./skills/`, and the logo asset
  resolves. See `INSTALL-CODEX.md`.

### Four-manifest check #19

`/lr:check` #19 and `conventions.md` § Plugin Manifest Versioning now cover
`.cursor-plugin/plugin.json` and `.codex-plugin/plugin.json` alongside the Claude manifests. The
Cursor bump is consistency hygiene (not a verified cache-detection lever); the Codex bump **is** the
version Codex reads for the plugin. The Codex `.agents/plugins/marketplace.json` carries no
per-plugin version and is not part of the check.

## Pre-ship verification

Per strand: **Cursor ops parity** was gated by the full `LR_LIFECYCLE=1` suite on `claude` at its
commit. **Codex native packaging** was validated live against `codex-cli` 0.142.5 (clean teardown +
re-register resolves the native `.agents/plugins/marketplace.json`; `codex plugin add` installs at
`1.25.0` with the version resolved from `.codex-plugin/plugin.json`; cache snapshot carries manifest,
marketplace file, 30 canonical skills, and logo). **The workspace slice** was validated with
`workspace-pull` script smoke tests over a local two-level git fixture — two-level clone,
idempotent re-run, non-git workspace, git-workspace `.gitignore` plumbing, backward-compat
(domain-only), and unsafe-URL rejection — plus a lightweight haiku skill-invocation smoke test.
`/lr:check` and `claude plugin validate --strict` run clean. The complete `LR_LIFECYCLE=1` suite
remains the final gate before the v25 push.
